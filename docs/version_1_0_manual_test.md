## 判定メモ

- 結果は `OK`、`NG`、`保留`、`未実施` のいずれかで記録する
- NGの場合は、再現入力と実際の返答をメモに残す
- 実DBを使う確認では、不要なテスト記憶を残さない
- 危険操作、外部送信、削除、購入、配信開始は実行しない

## Ver1.0前の確認方針

Ver1.0は完成版ではない。
最低限の会話、記憶、安全確認、未実装機能の正直な扱いを、人間が確認できる最初の実用テスト版とする。
