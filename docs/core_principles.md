# Core Principles

## 最終目標

PersonalAIを、ユーザーの作業の中心入口にする。

最終的には、ユーザーが他のアプリを直接触らなくても、PersonalAI経由でほぼすべての作業を進められる状態を目指す。

PersonalAIは、会話、記憶、判断、実行、安全確認、文書作成、外部ツール利用を統括する存在として育てる。

## 最重要品質

回答精度を最重視する。

ユーザーが本当に聞きたいこと、やりたいことに正確に到達することを最優先する。

機能数を増やすことより、以下を重視する。

- ユーザーの意図を理解する
- 情報不足を見抜く
- 必要なら追加質問する
- 不確かなことを断定しない
- 未実装機能をできたふりしない
- 求められている回答に近づく

## 安全方針

ユーザーに影響する操作は必ず許可を取る。

未実装機能をできたふりしない。

外部送信やファイル操作などは必ずPermissionManagerを通す。

CapabilityManagerは「現在のPersonalAIでできるかどうか」を判断する。
PermissionManagerは「その操作を実行してよいか」を判断する。
Web ReaderやPDF Readerなどが未実装の場合は、許可確認へ進む前に未実装と返す。

特に以下は勝手に実行しない。

- ファイル作成
- ファイル編集
- ファイル削除
- 外部送信
- Git commit / push
- PC操作
- Webアクセス
- 個人情報処理
- 外部API利用

## 開発方針

```text
小さく実装する。
後から変更しやすくする。
壊れにくくする。
チェック可能にする。
docsを更新する。
Gitでこまめに保存する。
```

実装では、既存機能を壊さないことを重視する。
大きな変更を一気に入れず、checkスクリプトで確認できる単位に分ける。

## 自律性の方針

AIは提案してよい。

ただし、ユーザーに影響する実行は勝手にしない。

将来的には、ユーザーが許可した範囲では自動実行できるようにする。

想定する許可の種類:

- 今回だけ許可
- この種類の操作は今後も許可
- このプロジェクト内だけ許可
- このフォルダ内だけ許可
- 高リスク操作は毎回確認

## 記憶方針

重要な記憶は保存する。

間違った記憶は物理削除ではなく `is_active=False` で無効化する。

無効化した記憶はMemoryContextに渡さない。

自動忘却は、まずdry-runで候補提案だけを行う。
ユーザー確認なしに記憶を忘れない。
自動削除も自動無効化もしない。
将来的には、候補表示、ユーザー確認、`is_active=False` の順に進める。
物理削除は原則しない。

好き嫌いなどのPreferenceは、追加・更新・嫌いへの変更を扱う。

記憶確認はしすぎない。

Preferenceの基本方針:

- 好きなものが増えた場合は追加記憶として扱う
- 同じ対象について好き/好きじゃない/嫌いが変わった場合は同じmemory_keyで更新する
- 一番好き、今は、前は、変更などの曖昧な更新意図は確認質問の候補にする
- 確認質問後の回答は、1件だけpendingとして保持してから処理する
- pendingはDBに保存せず、PersonalAIインスタンス内の一時状態として扱う
- 一番好きな食べ物は `preference:food:primary` に保存する
- 確認回答処理はPreference記憶の保存に限定し、ユーザーに影響する大きな操作とは分けて考える

## 未実装機能の扱い

未実装機能は未実装と返す。

読んでいないWebページ、PDF、YouTube、画像を読んだふりしない。

作成していないWord / Excel / PDFファイルや、操作していないPC操作を実行したふりしない。

Qwenで難しい作業や、法律・医療・論文レベルの高精度判断は限界を説明し、OpenAI接続後の予定として扱う。

未実装の代表例:

- OpenAI接続
- Claude / Gemini接続
- Webページ実読み取り
- YouTube実要約
- PDF読み取り
- 画像読み取り
- Word / Excel / PDF作成
- PC画面読み取り
- PC操作
- ベクトルDB
- Embedding検索
- Knowledge DB本格実装
- GUI

## Ver1.0の考え方

Ver1.0は完成版ではない。

Ver1.0は、最低限の会話・記憶・安全確認を実用に近い形でテストできる最初の版である。

Ver1.0までに大事なのは、巨大な機能追加ではなく、以下を安定させることである。

- 会話できる
- 記憶できる
- 記憶を使える
- 間違った記憶を無効化できる
- 未実装機能をできたふりしない
- 危険操作を勝手に実行しない
- PC上で重すぎず動く
